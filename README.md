# 🎯 Анализатор Крутых ID Тредов

Скрипт для экспорта и анализа ID тредов с форума **lolz.live**, который находит интересные числовые паттерны в идентификаторах тредов.

## 📋 Описание

Этот инструмент подключается к API lolz.live, загружает все треды конкретного пользователя и анализирует их ID на предмет различных числовых паттернов: палиндромов, последовательностей, повторений и других интересных комбинаций.

## 🚀 Установка

### Требования

- Python 3.7+
- pip

### Шаги установки

1. Клонируйте репозиторий или скачайте файлы:
```bash
git clone <url-репозитория>
cd <папка-проекта>
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## ⚙️ Настройка

Создайте файл `config.env` со следующими параметрами:

```env
API_URL=https://prod-api.lolz.live/threads
CREATOR_USER_ID=ваш_user_id
BEARER_TOKEN=ваш_bearer_token
```

### Как получить токен

1. Войдите на сайт **lolz.live**
2. Перейдите в настройки API
3. Создайте новый токен с необходимыми правами (как минимум `read`)
4. Скопируйте токен и вставьте в `config.env`

## 📖 Использование

Запустите скрипт:

```bash
python export_threads.py
```

### Что делает скрипт:

1. **Экспорт данных** 📥
   - Подключается к API lolz.live
   - Загружает все треды указанного пользователя
   - Сохраняет ID в `thread_ids.json`

2. **Анализ паттернов** 🔍
   - Проверяет каждый ID на различные числовые паттерны
   - Классифицирует найденные комбинации
   - Отображает результаты в консоли

3. **Сохранение результатов** 💾
   - Создает файл `cool_thread_ids.json` с детальной информацией
   - Включает статистику и топ найденных ID

## 🛠️ Технологии

- **requests** - для HTTP-запросов к API
- **python-dotenv** - для загрузки переменных окружения
- **collections** - для анализа данных (Counter, defaultdict)

```

├── requirements.txt        # Зависимости Python
```

## ⚠️ Важно

- **Не коммитьте** файл `config.env` с вашим токеном в публичные репозитории!
- Скрипт делает задержку 0.5 секунды между запросами, чтобы не перегружать API
- Убедитесь, что ваш токен имеет права на чтение (`read`)
